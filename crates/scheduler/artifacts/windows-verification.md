# Windows scheduler verification

Verified locally on Windows x86_64 on 2026-10-02. These are native Rust results.

```powershell
. .\scripts\with-native-env.ps1
cargo test -p asset-scheduler -- --nocapture
cargo run -p asset-scheduler --release --example queue_benchmark -- C:\masset\crates\scheduler\artifacts\benchmark-results.json
cargo fmt -p asset-scheduler -- --check
```

- 31 unit tests passed, 0 failed; unit suite finished in 1.20 seconds.
- 2 integration tests passed, 0 failed; suite finished in 0.79 seconds.
- The child-process fixture exited with code 73 without Rust destructors during
  an unfinished SQLite write. Eight committed events, both external identity ids,
  and the 33-byte validated artifact survived; unfinished state/event writes were
  discarded. Local interrupted work became ready and external work remained unknown
  without resubmission. This is local state recovery, not a provider integration test.

The six jobs each performed 64 SHA-256 passes over a real 2 MiB input. Every serial

covers each child's lifetime. The benchmark queue was in-memory SQLite; disk/WAL
durability was tested separately. No Blender/provider throughput or macOS result
was measured in this scheduler run.
