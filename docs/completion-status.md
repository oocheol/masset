# 현재 완료 범위

2026-10-03, Windows 개발 환경 기준입니다. 0.1.1은 주요 글씨 확대·설명 접기·사용 가이드와 서명된 앱 내부 업데이트를 추가했습니다. 실제 포터블/설치형 창, 12개 이미지, 가이드, 네이티브 IPC, Blender GLB 렌더, 33개 백엔드 출력과 같은 버전 재설치·재시작·제거를 확인했습니다. 다른 버전의 실제 플러그인 설치, 다른 PC, macOS와 구독 이미지 수신은 미검증입니다. [버전별 검사](verification.md)와 [릴리스 메타데이터](releases/v0.1.1.json)를 참고하세요.

추론 모델은 GPT-6.1 Sol (`gpt-6.1-sol`), 이미지 목표는 GPT Image 2입니다. 서명된 공식 Codex `0.159.0-alpha.12.1`의 인증·로컬 준비를 읽기 전용으로 확인했습니다. 모델 권한은 `unknown`이며 새 생성 요청은 보내지 않았습니다.

다음 표는 원래 0.1.0의 2026-10-02 검사와 계획 기록입니다. 0.1.1의 최신 상태를 이전 실행 파일 결과로 대체하지 않습니다.

사용자가 GPT Image 2로 선택을 변경했으며, 이 모델의 실제 이미지 파일 실증은 완료되지 않았습니다. Windows의 포터블 실행과 로컬 백엔드 파일·버전·내보내기·실제 3D 렌더는 검증했습니다. 로컬 SHA-256 6개 작업을 별도 프로세스에서 한 번씩 실측해 직렬 761.0ms·병렬 447.5ms(1.70배), 동시 작업 1→2, CPU 시간 각 0.53125초, 프로세스 peak working set 8,519,680→10,657,792 bytes를 확인했습니다. 이 해시 fixture의 결과를 AI·Blender 처리 성능으로 일반화하지 않습니다. 공급자 파일 수신과 다른 PC·설치 수명주기는 남아 있어 전체 요구사항 완료로 표시하지 않습니다.

이미지 큐의 RAM 예약은 이미지 크기와 필터 버퍼를 기준으로 한 추정치입니다. OS가 강제하는 메모리 상한은 아닙니다. 가져오기·내보내기는 현재 직렬 명령이며, 내보내기 자체의 영속 큐 통합과 OS 메모리 제한도 남아 있습니다.

프로젝트 파일 잠금은 Rust 검사와 네이티브 백엔드의 독립 핸들로 동시 열기 거부·종료 후 해제를 확인했습니다. 이 검사의 범위는 같은 프로세스의 독립 핸들이며, 두 데스크톱 앱 인스턴스의 동시 접근 검사는 남아 있습니다. 스케줄러와 자식 작업자의 프로세스 강제 종료 복구는 별도의 Rust 검사에서 통과했습니다.

브라우저의 IndexedDB·Canvas·Three.js·ZIP 결과와 Blender 작업자 직접 실행은 각각 실제 파일 검증을 거쳤습니다. 둘은 Rust 백엔드, WebView 창 또는 설치 패키지의 성공 증거를 대신하지 않습니다.

현재 GLB는 glTF 표준 미터·Y-up, Blender 원본은 미터·Z-up입니다. cm/mm 입력은 미터로 환산합니다. 이름 규칙·대상 프로그램은 프로젝트 규격에 기록되며, 내보낸 원본/버전 경로는 UUID 기반으로 보존합니다. 자동 이름 규칙 적용은 아직 완료되지 않았습니다. 스타일의 팔레트·카메라·조명은 실제 Blender 렌더에 적용되며, 선 두께·디테일 문구·여백·참조 동일성의 미적용 범위는 보고서에 남습니다.
