# 이미지에서 3D · 모델 다듬기

**제작 화면**과 **3D 만들기**에서 Windows x64와 Apple Silicon Mac의 로컬 이미지→3D 경로를 사용할 수 있습니다. 프로젝트의 이미지 또는 GLB를 최대 5개 선택합니다. 이미지 한 장은 독립 모델 하나입니다. 기존 GLB는 원본 버전을 보존하고 새 버전을 만듭니다. 기본 소품 레시피는 같은 창의 별도 버튼으로 사용할 수 있습니다.

이미 다듬은 모델을 다시 조정할 때는 보존된 고해상도 형상을 우선 사용합니다. 삼각형 예산을 낮췄다가 다시 높여도 그 형상에서 새 게임용 모델을 만들며, 기존 게임용·고해상도·LOD 버전은 유지합니다.

1. 참고 자료를 가져옵니다. 이미지에는 물체 하나를 크게 담고, 배경과 접지 그림자를 제거하세요. 이미지 편집에서 배경·마스크를 수정한 PNG 버전을 사용할 수 있습니다. 잘린 물체, 글자, 여러 물체가 함께 있는 이미지와 매우 얇은 무기는 복원이 어려울 수 있습니다.
2. 최초 한 번 **로컬 3D 모델 준비**에서 다운로드에 동의합니다. Windows는 전용 Python 3.12.10·CPU 라이브러리·모델을 앱 데이터에 준비합니다. 총 2,034,000,316바이트(약 1.89GiB)이며 Python·CUDA·개발 도구를 별도로 설치할 필요가 없습니다. Mac은 기존 CPython 3.9 경로를 사용합니다. 두 플랫폼 모두 최소 16GB 메모리와 별도 설치한 Blender가 필요합니다. 입력 이미지는 전송하지 않으며, 준비 후 모델 추정은 CPU에서 실행합니다. GLB 다듬기에는 이 모델 다운로드가 필요하지 않습니다.
3. 높이(m), 프로젝트 폴리곤 예산 이하의 삼각형 수, 텍스처 해상도와 형상 추정 품질을 정하고 제작합니다. 큐는 입력별로 실행하며 취소하면 원본과 이미 만들어진 중간 파일을 보존합니다. CPU 작업에는 수 분이 걸릴 수 있습니다.

완료된 에셋에는 게임용 GLB, 고해상도 형상, LOD 1, 편집 가능한 Blender 원본, UV에 베이크한 기본 색상 텍스처, 지원되는 경우 형상에서 베이크한 노멀맵, 썸네일·턴테이블, 파일 검증 보고서가 포함됩니다. GLB는 텍스처를 내장하고 미터·Y-up을 사용합니다. 독립 내보내기에는 각 파일의 SHA-256과 상대 경로를 기록합니다. 3D 화면의 **표시 모델**에서 게임용·고해상도 원본·LOD 1을 비교하세요.

이미지 형상 추정은 MIT 라이선스의 오픈 모델 **TripoSR**을 사용합니다. Tripo Studio의 현재 H3.1 서비스와는 다른 모델입니다. 동일한 품질, 다중 시점 복원, 리깅, 쿼드 리토폴로지, 8K 텍스처를 제공한다고 주장하지 않습니다. 이미지에 보이지 않는 뒷면은 추정하며 결과는 직접 확인해야 합니다. 기존 모델 다듬기는 형상·재질을 보존하며 예산 조정과 UV·파일 정리를 수행합니다. 없던 세부 형상을 생성하는 기능은 아닙니다.

Windows 준비 파일은 Python.org, 공식 PyTorch CPU 배포처, PyPI, GitHub와 Hugging Face의 고정 버전에서 받습니다. 각 파일의 출처·용량·SHA-256·라이선스는 [Windows 런타임 명세](../workers/image3d/runtime-lock-windows.json)에 있습니다. Python은 PSF, TripoSR은 MIT이며 의존성에는 BSD·Apache-2.0·MPL-2.0 등이 포함됩니다. 다운로드·설치 검증과 실제 추론 성공은 구분하며, 실제 파일 검증 기록은 [릴리스 기록](releases/)으로 확인하세요.

원본 코드·가중치의 고정 리비전, 별도 라이선스와 실행 경로는 작업별 생성 보고서에 기록합니다. 생성 도중 모델을 새로 내려받거나 유료 API로 대체하지 않습니다. Blender는 `--factory-startup --disable-autoexec`로 실행하며 입력 `.blend`나 생성된 스크립트는 실행하지 않습니다.

Windows의 PyTorch는 Microsoft Visual C++ 2015–2022 x64 런타임의 `MSVCP140.dll`이 필요합니다. 없으면 모델 다운로드를 시작하지 않고 설치 안내를 표시합니다. [Microsoft 공식 런타임 안내](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)를 확인하세요. 이 앱은 VC++ 설치 파일을 자동 다운로드하지 않습니다.
