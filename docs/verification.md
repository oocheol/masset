## Reproduce local checks

```powershell
npm ci
$env:Path = "$env:USERPROFILE\.cargo\bin;$env:Path"
. .\scripts\with-native-env.ps1
cargo test --workspace
npm run typecheck
npm test
npm run build
npx playwright test
.\tests\blender\run-tests.ps1
.\scripts\build-windows.ps1 -SkipInstall
cargo build -p asset-desktop --bin asset-cli
.\scripts\native-smoke.ps1
.\scripts\native-smoke.ps1 -NativeWindow
npm run verify:artifacts -- 'C:\exports\asset-bundle'
```

`tests/artifact` exercises corrupt data, digest mismatches, transparent empty output and path traversal using local fixtures. `scripts/verify-artifacts.mjs` reads only an export's manifest/files, never the producing database. It fully decodes PNG CRC/pixels, tests active dimensions, and loads GLB with independent Three.js GLTFLoader to inspect indexed geometry, finite positions/normals/UVs, valid materials, non-planar bounds and dimensions. It rejects external GLB buffers/textures. PNG texture pixels are decoded; other texture codecs are not silently certified.
Valid non-indexed glTF triangles are also supported; when indices exist each is validated against its vertex array. UV item size/count, normal lengths within 0.001 of one and explicit material references are checked independently. `maxNormalDeviation` records the observed deviation; the deliberate length-0.8 fixture is rejected.

It proves actual file decoding and geometry, not app storage/export integration. `.blend` hashing is checked in Node; source reopening is a separate fresh Blender process check. Local `output/` evidence is retained in this workspace and is regenerated by scripts rather than guaranteed present in a fresh checkout.

node tests/artifact/inspect-blender.mjs 'tests/blender/artifacts/crate-current-02' 'output/qa/fresh-independent-crate'

Atlas metadata is checked for bounds and overlapping frames. Exact pixel comparison is performed when the manifest/metadata includes the corresponding source PNG paths. ## Release evidence requirements

Record actual package paths/bytes/SHA-256, Authenticode or Apple signature/notarization status, tested OS/architecture, launch evidence, generated fixture/procedural artifact locations and independent reports. Do not publish automatically. Tests must preserve imported files, use new version/output directories, and clearly distinguish completed local work from uncertain remote generation.
