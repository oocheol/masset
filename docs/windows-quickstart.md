# Windows 사용 안내

포터블 ZIP 전체를 원하는 폴더에 풀고 `asset-desktop.exe`를 실행하세요. `examples`와 `workers` 폴더도 함께 두어야 합니다. Node.js·Rust·Visual Studio는 앱 사용에 필요하지 않습니다. Windows WebView2가 필요하며, 현재 개발 PC에서는 실행을 확인했습니다. 실행 파일은 미서명입니다.

## 첫 에셋 묶음

1. 프로젝트를 만들고 규격의 크기·단위·스타일을 정합니다. 제공 예제는 로컬 샘플이며 AI 생성 결과가 아닙니다.
2. PNG/JPEG/WebP 파일을 가져옵니다. 원본은 보존하고 변환 결과를 새 버전으로 기록합니다.
3. 이미지를 선택해 크기 조정·색상·배경 처리를 실행합니다. 여러 이미지를 선택하면 아틀라스와 좌표 JSON을 만들 수 있습니다.
4. 결과의 검사 상태와 버전을 확인한 뒤 새 폴더로 내보냅니다. 파일과 manifest가 함께 저장됩니다.
5. 앱을 닫고 프로젝트를 다시 열면 에셋·버전·작업 상태를 복원합니다.

## 3D 소품

Blender를 별도로 설치해야 합니다. 앱은 Blender를 자동 다운로드하지 않습니다. 이 Windows 버전은 Blender 5.2.1에서 검사했습니다. 상자·테이블·선반의 치수와 재질을 정하면 GLB, 편집 가능한 `.blend`, 미리보기 이미지를 만듭니다. GLB는 미터·Y-up이며 제조용 CAD 도면이 아닙니다.

## ChatGPT 구독 이미지

공식 Codex를 설치하고 ChatGPT 계정으로 로그인한 뒤 앱의 구독 연결 확인을 사용합니다. 이미지 목표는 GPT Image 2이고, 추론 모델은 별도로 고정합니다. 설명과 승인한 스타일·규격이 공식 런타임에 전달되며 구독 한도를 사용할 수 있습니다. API 키 결제로 자동 전환하지 않습니다.

연결 성공과 실제 이미지 생성 성공은 다릅니다. 현재 검증 결과는 [공급자 실증](provider-feasibility.md)을 확인하세요. 원격 결과를 확인하지 못한 작업은 ‘결과 불명’으로 남으며 자동으로 재요청하지 않습니다. 실제 사용 이미지 모델이 응답에 없으면 확인되지 않았다고 표시합니다.

## 작업과 복구

작업 큐에서 진행·오류를 확인할 수 있습니다. 취소 후 실행 중인 로컬 작업이 종료돼야 재실행하거나 프로젝트를 전환할 수 있습니다. 완료 결과 재사용은 저장된 파일의 해시를 확인하며, 재실행은 새 버전을 만듭니다. 외부 결과 불명 작업을 새 요청으로 보내면 중복 생성될 수 있으므로 기존 결과를 먼저 확인하세요.

macOS 설치본, 다른 Windows PC에서의 실행, 설치·업그레이드·제거 수명주기는 현재 배포본의 개발 PC 검사와 구분합니다. 자세한 상태는 [플랫폼 지원](platform-support.md), 실제 검사 결과는 [검증 기록](verification.md)에 있습니다.
