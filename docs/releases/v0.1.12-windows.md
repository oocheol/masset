# Asset Studio 0.1.12 · Windows 앱과 npm 스킬

최신 master의 제작 화면 디자인을 Windows에 반영하고, Windows 앱·독립 CLI와 npm 패키지 `@oocheol/asset-studio`를 **0.1.12**로 배포했습니다. npm 스킬은 **Asset Studio 앱 설치 없이 Codex에서 사용**할 수 있습니다. 기존 프로젝트와 원본을 보존하고, 편집 결과는 새 버전으로 저장합니다.

Apple Silicon Mac 앱은 기존 **0.1.12**, 독립 Mac CLI는 기존 **0.1.11**을 유지합니다. 이번 작업은 Windows 빌드이며 Mac 패키지와 `latest-macos.json`을 변경하지 않았습니다. Intel Mac 패키지는 제공하지 않습니다.

## 설치와 업데이트

Node.js 22.20 이상에서 다음 명령으로 스킬을 등록합니다. 등록 후 새 Codex 작업에서 **`$asset-studio 게임 에셋을 만들어줘`**라고 요청하세요. 기존 공식 Codex의 인증을 재사용하며, 인증이 없거나 만료된 경우에만 로그인이 필요합니다. 스킬의 첫 사용 시 고정 크기·SHA-256·파일 목록을 검증한 네이티브 CLI를 사용자 전용 공간에 준비합니다. 3D 작업에 필요한 Blender·Python·모델 다운로드는 승인된 범위 안에서 진행합니다.

```sh
npx @oocheol/asset-studio@latest install
npx @oocheol/asset-studio@latest update
```

기존 Windows 앱은 업데이트 패널에서 **0.1.12**를 확인해 설치합니다. 앱 업데이트는 서명된 Windows 설치 패키지를 사용합니다. 포터블 사용자는 전체 폴더를 새 위치에 풀어 실행합니다.

| npm 설치·업데이트 | 공개 npm 파일 일치와 새 캐시 설치 확인. 0.1.11 → 0.1.12 업데이트에서 이전 스킬·기록·추가 사용자 파일 보존; 반복 업데이트는 변경 없음 |
| Windows 스킬 첫 준비 | 기본 PowerShell 5.1에서 공개 CLI ZIP을 실제 다운로드·파일 377개 검증·사용자 전용 런타임 준비 |

이번 0.1.12에서는 새로운 GPT 이미지 생성이나 TripoSR CPU 추론을 요청하지 않았습니다. 실제 Windows TripoSR CPU 추론은 [0.1.11 검증](v0.1.11-windows.md)에 기록돼 있습니다. 별도 새 PC 설치, 기존 설치를 교체하는 업데이트·재시작 전체 과정은 확인하지 않았습니다. 공개 updater 검사는 0.1.11 검사 클라이언트에서 다운로드 경로를 확인한 것으로 설치 프로그램을 실행하지 않았습니다. Windows Authenticode 서명은 적용되지 않았으며 Tauri 업데이트 서명과 구분합니다.
