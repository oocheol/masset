# Asset Studio 0.1.11 · Windows 앱과 독립 Codex 스킬

Windows x64에서 **Asset Studio 앱을 설치하지 않고 Codex 스킬만으로 에셋을 제작**할 수 있습니다. 처음 사용할 때 고정 해시를 검증한 네이티브 CLI를 준비하고, 기존 공식 Codex 로그인을 재사용합니다. 3D를 요청하면 필요한 Blender·Python·TripoSR도 다운로드 승인 범위 안에서 사용자 전용 공간에 준비합니다. 앱의 제작 화면과 프로젝트·원본·버전 보관 방식은 유지합니다.

이번 배포는 **Windows 전용**입니다. Mac 앱과 업데이트 채널은 기존 **0.1.10**을 유지하며, 새로운 독립 Mac CLI 패키지는 별도로 빌드·검증·배포해야 합니다. Intel Mac 패키지는 제공하지 않습니다.

## 시작하기

스킬 설치 후 새 Codex 작업에서 **`$asset-studio 필요한 도구를 설치하고 게임 에셋을 만들어줘`**라고 요청하세요. 스킬 자체는 실행 파일과 모델을 포함하지 않습니다. 출처·버전·크기·SHA-256·라이선스를 표시하고 승인된 구성요소만 받습니다. 이미 설치를 승인했다면 같은 다운로드 동의를 반복해서 요청하지 않습니다.

- **2D 작업:** 독립 CLI로 시작하며 Blender·모델을 다운로드하지 않습니다. Node.js·Rust·별도 Asset Studio 앱은 필요하지 않습니다.
- **구독 제작:** 기존 공식 Codex의 ChatGPT 인증을 사용합니다. 인증 정보는 복사하지 않습니다. 로그인이 없거나 만료된 경우에만 공식 로그인 절차가 필요합니다. 준비 과정은 이미지를 생성하지 않습니다.
- **3D 작업:** `prepare --needs-3d --consent-downloads`로 준비합니다. Windows는 최소 16GiB RAM과 Microsoft Visual C++ 2015–2022 x64 런타임이 필요합니다. 없는 시스템 런타임은 명시적으로 안내하며 관리자 권한 설치를 자동 실행하지 않습니다.
- **로컬 편집만:** `prepare --local-only`는 구독 상태와 Codex 설치를 확인하지 않습니다. CLI 설치, 로컬 3D 준비, 계정 연결 결과는 각각 확인합니다.
- **기존 앱 사용자:** 앱 업데이트 패널에서 Windows 0.1.11을 확인하고 설치합니다. 프로젝트와 원본은 새 파일로 보존합니다.

새 GPT 이미지 요청과 깨끗한 PC의 최초 설치, 기존 설치본 교체·재시작은 이 버전의 검증 범위에 포함하지 않습니다. 계정 인증 확인만으로 이미지 모델 권한이나 실제 생성 성공을 보장하지 않습니다. 공개 다운로드와 네이티브 updater 검증 결과는 [배포 메타데이터](v0.1.11-windows.json)에 기록합니다. Windows Authenticode 코드 서명은 없으며 업데이트 파일 서명과 별개입니다.

TripoSR은 단일 이미지에서 정적인 메시를 추정합니다. 입력에 따른 형상·뒷면의 부정확성, 리깅·쿼드 리토폴로지·실제 물리 치수의 검증 범위는 [모델 안내](../model-quality.md)를 확인하세요.
