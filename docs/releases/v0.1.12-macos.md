# Asset Studio 0.1.12 · 제작과 검수 중심의 디자인

Mac 앱과 운영 홈페이지의 디자인을 개선했습니다. Windows 앱·포터블·독립 Codex 스킬·CLI·npm 설치기는 기존 0.1.11 배포를 유지합니다. Windows 새 빌드는 추후 별도로 진행합니다.

- 제작 홈의 설명·연결 상태·제작 목록을 정리하고 완료 수와 항목별 상태를 명확히 표시합니다.
- 보관함·결과 확인으로 이동해도 제작 입력을 보존합니다.
- 앱·홈페이지·README·공유 이미지에 공통 색상과 타이포그래피를 적용했습니다.
- 홈페이지의 Codex 시작·플랫폼별 설치 안내를 분리하고 실제 자체 제작 렌더와 현재 브라우저 화면을 제공합니다.

## 검증과 제한

제작 UI 회귀 테스트 35개, 데스크톱 TypeScript/Vite·사이트 TypeScript/Vite 빌드, 앱 1100×720·1500×960과 사이트 320·390·768·1440px 브라우저 레이아웃, 일부 텍스트·컨트롤 대비, 키보드 포커스·Escape·모션 감소를 점검했습니다. 브라우저와 모의 desktop 명령 테스트는 네이티브 실행 검증으로 표시하지 않습니다.

Apple Silicon arm64 앱·DMG·프로젝트 키로 서명된 업데이트를 제공합니다. 실제 배포 바이트의 크기·SHA-256·앱 버전·서명 무결성과 업데이트 서명·인증된 버전·변조 거부 검증 결과는 [배포 메타데이터](v0.1.12-macos.json)에 기록합니다. DMG는 잠금 상태에서도 Finder 자동화 없이 생성합니다. 설치 스크립트의 check-only는 파일을 검사하며 사용자의 앱을 설치·실행하지 않습니다.

**Mac이 잠겨 있어 네이티브 화면 실행·실제 DMG 설치·기존 앱 업데이트 교체·새 GPT 생성·로컬 3D 생성 검증을 생략했습니다.** Windows 새 빌드·실행도 수행하지 않았습니다. Apple Developer ID 서명·공증은 없으며 앱의 ad-hoc 서명과 프로젝트 업데이트 서명은 Apple 공증과 별개입니다. Intel Mac은 제공하지 않습니다. 기존 앱·다운로드·사용자 프로젝트·원본을 수정하거나 삭제하지 않습니다.

독립 CLI와 Codex 스킬은 기능 변경이 없어 0.1.11의 고정 URL·해시를 유지합니다. 최신 GitHub 릴리스에는 기존 Windows latest.json을 동일한 바이트로 제공하여 Windows 업데이트 채널이 끊기지 않게 합니다. Windows 0.1.11 다운로드는 기존 릴리스로 연결합니다.
