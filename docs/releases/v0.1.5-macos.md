# Asset Studio 0.1.5 · Mac GPT 구독 연결

Apple Silicon Mac의 GPT 구독 연결과 앱 전용 공식 Codex 준비를 추가했습니다. 2026-10-04, macOS 27.0.1 arm64에서 실행한 결과입니다. 패키지 소스는 `516fe909a2255e756e4ae3f36be8efd154f3f196`입니다. Windows 공개 앱은 0.1.3을 유지합니다.

## 연결과 개별 이미지 수신

공식 ChatGPT/Codex 앱 안의 네이티브 Codex 실행 파일과 이미지 호스트에서 OpenAI Developer ID 팀 `2DC432GLL2`, arm64 아키텍처와 코드 서명을 확인해 재사용합니다. 기존 공식 Codex 인증은 공개 app-server의 계정 상태로 확인하며 앱이 인증 파일이나 토큰을 읽지 않습니다.

Codex가 없는 환경에서는 공식 0.160.0 Apple Silicon 패키지의 129,976,298바이트와 SHA-256 `007df41b607dbbc8d204b9746ce7fed2d4ce6c813f44c32ceee54175ca796525`를 검사합니다. 동의·검토 해시 강제, 안전한 압축 해제, 실행 권한, OpenAI 서명과 등록을 실제로 확인했습니다. 빈 Codex 홈에서 공개 RPC에 연결해 미로그인 상태·제어 설정·이미지 도구를 확인했습니다.

별도 QA 프로젝트에서 실제 새 이미지 요청 **1회·시도 1회**를 실행했습니다. 1254 × 1254 PNG, 565,884바이트, SHA-256 `bc25c4a6bafaf6e493068c18461751cfb9c629214dda5522d9302bf754056abb`를 수신하고 독립 디코더의 CRC·해시 검사, 저장·재열기·내보내기를 통과했습니다. 추론 모델은 `gpt-6.1-sol`, 요청 이미지 모델은 `gpt-image-2`이며 응답의 실제 이미지 모델 ID는 null입니다. 계정별 모델 권한과 사용 한도는 별도입니다.

## 실제 배포 파일과 업데이트

- DMG: `AssetStudio_0.1.5_macos-arm64.dmg`, 27,171,608바이트, SHA-256 `bcdf15364201fdfa78146e93a32a0728b2416b64e67e1d5bb2c274ab22945ea2`.
- 서명된 업데이트: `AssetStudio_0.1.5_macos-arm64.app.tar.gz`, 28,060,098바이트, SHA-256 `12aa507f41e273010a60382f69e65fc679d507371e18193574aa2880513cb94e`.
- 설치 스크립트: SHA-256 `fff494de08776b20cb0415e4e47cca32a43acfd1cf2ea664b67eae4e2fa71d01`. 실행 전에 스크립트 해시를 확인하며 공개 DMG를 검증해 새 앱을 설치했습니다.
- GitHub 파일 8개의 익명 다운로드가 실제 로컬 배포 파일과 크기·해시 모두 일치합니다. Windows `latest.json`은 0.1.3의 바이트를 그대로 유지합니다.

Finder 권한을 사용하는 일반 DMG 빌드가 성공했습니다. 실제 DMG에서 복사한 앱 봉인·리소스·엄격한 Mac 라이선스 수집, 네이티브 WebView·IPC·이미지 12개를 확인했습니다. 별도 Rust 백엔드의 6개 작업, PNG 16개와 독립 내보내기도 통과했습니다. Rust 테스트 148개와 파일 검증 테스트 30개가 통과했습니다. 현재 `/Applications/Asset Studio.app`의 343개 파일·링크·실행 권한 항목은 최종 배포 앱과 일치합니다.

이번 업데이트 검증은 **과거 실제 공개 0.1.4 앱**을 별도 QA 폴더에 복사해서 실행했습니다. 실제 네이티브 승인 UI, 공개 0.1.5 후보 채널의 공식 Tauri 다운로드·서명·버전 검사, 앱 교체·새 PID 재실행을 통과했습니다. 프로젝트·버전·원본 파일 해시와 이미지 12개를 그대로 유지했으며 공급자 생성 요청은 하지 않았습니다. 0.1.3 이하에는 Mac 업데이트 기능이 없어 최신 앱을 한 번 직접 설치해야 합니다.

## 검증 범위

Asset Studio 자체는 ad-hoc 코드 서명이며 Apple Developer ID 서명·공증은 없습니다. 앱 업데이트의 별도 서명 키와 Codex의 OpenAI Developer ID 확인은 서로 다른 검사입니다. 최초 Gatekeeper 정책 수락, 깨끗한 하드웨어, 최소 macOS 12.0, Intel과 Mac Blender 3D는 이 릴리스에서 검증하지 않았습니다. 원본·기존 프로젝트·이전 검증 실패 기록은 보존했습니다.
