# Asset Studio 0.1.10 · Mac

2026-10-06 Apple Silicon Mac 배포입니다. Windows는 기존 0.1.9 다운로드와 업데이트 채널을 유지합니다.

## 변경 사항

- 앱에 네이티브 `asset-cli`와 **Codex 스킬 설치**를 추가했습니다. 게임 프로젝트를 읽는 Codex가 독립 에셋 목록을 작성하고 제작·엔진 반영·게임 구현을 이어갈 수 있습니다.
- 스킬 플러그인 ZIP을 함께 제공합니다. 별도 MCP 서버·포트·유료 API 키가 필요하지 않습니다.
- 긴 게임 설명의 제작 목록 분석 대기와 취소, 제작 큐 이어받기와 실패한 로컬 단계 재처리를 개선했습니다.
- 모델의 UV 결함을 제한된 범위에서 보정하고 Blender가 서명된 앱 내부에 Python 캐시를 쓰지 않도록 수정했습니다.
- GPT 구독 경로, 로컬 TripoSR·Blender, 개별 파일과 새 결과 폴더, 원본 보존을 유지합니다.

## 설치와 업데이트

[Mac 설치 안내](../macos-quickstart.md)의 터미널 설치 또는 DMG를 사용하세요. 최초 설치 기본 위치는 `~/Applications/Asset Studio 0.1.10/Asset Studio.app`입니다. 0.1.4 이상에서는 앱 업데이트 화면을 이용할 수 있습니다. Apple Developer ID 서명·공증은 없으며, 앱의 ad-hoc 서명과 프로젝트 키로 서명한 업데이트 파일은 Apple 공증과 구분합니다.

[Codex 연동 사용법](../codex-integration.md)에서 스킬 설치와 CLI 호출을 안내합니다. 스킬 탐색이 모든 요청의 자동 선택을 보장하지는 않으며 `$asset-studio`로 지정할 수 있습니다. 이미지 기반 모델은 정적 메시이며 리깅·캐릭터 애니메이션·게임 완성을 제공하는 모델은 아닙니다.

## 배포 범위

사용자의 명시적 요청으로 최종 패키지의 추가 단위 테스트·설치·네이티브 화면·업데이트 교체 실행·공개 파일 재다운로드 검증을 생략했습니다. 배포를 위해 프런트엔드와 Rust 네이티브 앱을 빌드하고 DMG, 서명된 업데이트 파일, 파일 크기·SHA-256과 두 플랫폼 업데이트 채널을 구성했습니다. 빌드 및 파일 패키징을 플레이 테스트나 설치 검증으로 표시하지 않습니다.

합치기 전 개발 검증은 [Codex 연동 기록](../codex-integration-validation.md), 이전 Mac 배포 검증은 [0.1.8 기록](v0.1.8-macos.md)에 남습니다. 새 Windows CLI·스킬, Intel Mac, 깨끗한 Mac 설치와 Codex의 게임 전체 제작·완성은 이번 범위에서 검증하지 않았습니다. 실제 배포 파일 정보는 [배포 메타데이터](v0.1.10-macos.json)와 릴리스의 `SHA256SUMS`를 참고하세요.
