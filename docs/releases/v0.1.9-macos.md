# Asset Studio 0.1.9 Mac · 긴 게임 설명 분석 수정

전체 게임의 이미지와 3D 에셋을 분석할 때 요청을 120초에서 중단하던 문제를 수정했습니다. 최대 120개 제작 목록을 구성하는 전체 게임 분석은 최대 10분 동안 응답을 기다립니다. 작은 에셋 묶음 분석의 기존 120초 제한과 개별 RPC 제한은 유지합니다. 긴 목록의 스트림을 4,096개 이벤트에서 중단하던 제한도 수정했습니다. 전체 게임 분석은 최대 65,536개 이벤트·64MiB 스트림을 허용하며 결과 JSON의 512KiB 제한과 도구 실행 차단은 유지합니다.

분석 화면은 실제 경과 시간을 표시하고 **분석 취소**를 제공합니다. 취소와 실패 시 설명·참고 자료를 보존하며 늦게 도착한 취소 요청의 구성안은 제작에 쓰지 않습니다. 로그인, 사용 한도, 입력, 제작 목록 형식, 시간 초과와 연결 끊김 오류를 자격 증명이나 원시 서버 출력 없이 안내합니다. 자동 재요청과 유료 API 대체는 하지 않습니다.

Unity의 파일 읽기 제한·패키지 GUID 경고는 분석 범위 안내이며 자체로 GPT 분석을 차단하지 않습니다. 사용자가 제공한 긴 Unity 6 게임 설명과 실제 Unity 프로젝트의 에셋 199개로 구독 분석을 확인했습니다. 수정 전에는 4,097번째 응답 이벤트에서 중단됐고, 수정 후에는 6,214개 이벤트를 처리해 약 80.44초에 이미지 36개·3D 모델 21개(총 57개)의 구성안을 받았습니다. 원본 프로젝트 분석 지문은 유지됐고 생성 작업은 제출하지 않았습니다. 계획·미검증 범위와 경고를 반환했으며 게임 구현이나 캐릭터 리깅을 완료했다고 주장하지 않습니다.

플래너 회귀 검사 27개, 전체 공급자 검사 74개(1개 제외), Mac 제작 백엔드 검사 8개와 화면 검사 31개를 통과했습니다. Mac arm64 0.1.9 설치본의 번들 봉인·현재 작업자/문서/라이선스 일치·Tauri WebView·IPC·프로젝트 분석·이미지 12개 디코딩을 확인했습니다. 이전 앱은 `.app.backup`으로 보존하고 기존 프로젝트 65개 파일과 GPT 인증의 해시를 유지했습니다. 업데이트 아카이브의 서명·인증된 버전과 변조 거부도 확인했습니다. 설치된 앱에서도 동일한 설명과 프로젝트로 실제 GPT 분석을 다시 완료했습니다. 이미지 41개·3D 모델 18개(총 59개)의 제작 계획이 화면에 표시되고 제작 버튼이 활성화됐습니다. 기존 미디어 파일 29개의 해시와 작업 상태를 유지했고, 생성 작업은 제출하지 않았습니다. 설명을 정확히 복원했습니다. 공개 Windows/Mac 설치 파일은 기존 0.1.8을 유지합니다.
