# Asset Studio 0.1.7 릴리스 후보 · 로컬 이미지에서 3D와 모델 다듬기

투명 배경의 단일 물체 이미지를 개별 3D 메시로 복원하고, 기존 GLB는 원본을 보존한 새 버전으로 다듬습니다. 최대 5개의 입력을 한 번에 큐에 제출할 수 있습니다. 게임용·고해상도 형상·LOD, UV 색상 텍스처, 지원되는 경우 메시에서 베이크한 노멀맵, 편집 가능한 Blender 원본, 썸네일·턴테이블을 함께 저장합니다. 뷰포트에서 게임용·고해상도·LOD를 고르고 실제 삼각형 수를 확인할 수 있습니다.

2026-10-04, macOS 27.0.1 arm64, Apple M4 Pro·24GiB 메모리·시스템 CPython 3.9.6·Blender 5.2.1 LTS에서 검증했습니다. 이미지 복원은 최소 16GiB 호스트 메모리와 CPython 3.9를 요구하고, 한 작업에 8GiB를 예약합니다. 최초 동의 후 고정 코드·가중치·의존성을 준비하며 이후 CPU에서 오프라인으로 실행합니다. 원본 입력, 인증 파일과 기존 프로젝트를 덮어쓰지 않습니다. Windows 검증과 배포는 후속 작업이며 공개 Windows 버전은 0.1.3입니다.

## 실제 산출물

게임 에셋 묶음으로 만든 실제 무기 PNG와 기존 우주선 GLB를 한 번에 제출했습니다. 무기에는 높은 품질의 TripoSR 복원을 적용하고 15,943개 삼각형의 고해상도 모델에서 9,799개 삼각형의 게임 모델·LOD를 만들었습니다. 우주선은 기존 원본을 유지하고 두 번째 버전으로 저장했습니다. 두 작업은 약 78초 만에 완료됐습니다. 모든 입력 해시를 보존했고 저장·재열기·독립 내보내기를 통과했습니다. 두 결과의 GLB·LOD·`.blend`를 별도 Blender 프로세스에서 열어 총 109개 검사를 통과했습니다. [파일별 실제 백엔드 결과](v0.1.7-quality3d.json)를 확인하세요.

TripoSR의 예측 sRGB를 GLB의 선형 FLOAT32 `COLOR_0`으로 변환해 색이 밝아지는 오류를 수정했습니다. 높은 해상도의 무기에서 수치상 면적이 거의 없는 삼각형 하나를 제한된 허용 오차로 제거했으며, 이로 생긴 작은 경계는 보고서에 남겼습니다. 기존 GLB의 UV·노멀 이음새를 정리한 뒤 폴리곤을 줄여 검은 줄이 생기는 오류도 수정했습니다. 실제 RGB·PBR·발광 텍스처를 포함한 별도 모델은 69개 재열기 검사를 통과했습니다. 물체 색상에서 새로운 PBR 물성을 추정한다고 주장하지 않습니다.

실제 DMG에서 복사한 앱의 Tauri WebView·Mac IPC와 이미지 12개를 확인했습니다. 새 제작 화면에서는 입력 5개와 각각 하나의 모델이라는 안내, 품질·규격·예산 설정을 검사했습니다. 이 화면 검사는 로컬 모델 준비 상태를 모의 처리하고 제출을 가로채므로 실제 복원이나 다운로드의 증거가 아닙니다. 실제 복원은 위의 별도 네이티브 백엔드 기록으로 확인합니다.

Mac Rust 검사 175개, 프런트엔드·산출물 검사 67개, 로컬 모델의 실제 CPU·색상·입력 경계 검사 24개와 Blender 입력 검사 8개를 통과했습니다. Mac 대상 라이선스 수집은 npm 20개·Cargo 316개·라이선스 텍스트 257개·MPL 소스 5개이며 누락은 없습니다.

## 배포 검증 상태

앱·서명된 업데이트 아카이브와 APFS DMG를 빌드했습니다. DMG 체크섬과 내부 앱 376개 파일·링크의 최종 빌드 일치를 확인했지만, 현재 Mac의 HFS·APFS 볼륨 루트 목록 읽기가 멈추고 `hdiutil attach` 완료가 시간 제한을 넘었습니다. 최종 마운트·해제 수락 검사는 실패로 보존했습니다. 0.1.7 공개 다운로드·설치 스크립트·교차 버전 업데이트와 사이트 배포를 보류하며 공개 최신 Mac은 0.1.6입니다.

현재 `/Applications/Asset Studio.app`은 검증한 0.1.7 앱으로 교체했습니다. 이전 앱은 `.app.backup` 이름으로 복구 가능한 사본을 보존했고, 기존 프로젝트 63개 파일의 해시가 그대로 유지됐습니다. 설치본의 번들 봉인·현재 작업자와 라이선스 일치·실제 Tauri 화면을 확인했습니다. 앱 전용 폴더에 새 CPython 3.9.6 실행 환경을 만들고 고정된 캐시를 재검증했습니다. 설치된 앱의 작업자로 높은 품질의 무기 메시 15,943개 삼각형을 실제 복원하고 독립 파서로 다시 열었습니다. 원본 이미지 해시와 오프라인 CPU 실행을 확인했으며 이 실행 환경은 준비와 실제 복원 검증을 모두 완료했습니다.

APFS DMG는 33,618,446바이트, SHA-256 `e52ad52ef0a283d243f6d2374db4acf036df91edeffb64ebc7e1ad4581f6696c`입니다. 서명된 업데이트 아카이브는 30,397,175바이트, SHA-256 `911d5774703280c1ef9494b2b9ec2d820be7914cf4fabc85b46023f07d95fc23`입니다. 로컬에서 업데이트 서명·인증된 버전·변조와 다른 버전으로의 재사용 거부를 확인했습니다. 실제 공개 다운로드·Tauri 업데이트 설치·재시작의 증거와 구분합니다.

## 결과 범위

이미지 복원은 구형 오픈 모델 TripoSR이며 현재 Tripo Studio H3.1과 다른 모델입니다. 얇고 각진 무기의 기계적 세부 형상과 보이지 않는 뒷면에는 한계가 있습니다. 다중 시점 복원, 자동 리깅, 쿼드 리토폴로지·8K 텍스처·CAD 품질을 제공하지 않습니다. LOD는 게임용 UV를 이어받고 별도의 노멀 재베이크를 하지 않습니다. Blender는 `--factory-startup --disable-autoexec`로 실행합니다.

Apple Developer ID·공증, Intel·최소 macOS 12·깨끗한 하드웨어와 최초 Gatekeeper 수락은 검증하지 않았습니다. Mac 화면이 잠겨 있어 3D 뷰포트 GPU 픽셀 검사는 완료로 기록하지 않았습니다. 네이티브 생성·렌더 PNG·GLB·`.blend` 재열기는 별도로 통과했습니다.
