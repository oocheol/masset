# Asset Studio 0.1.2 — 쉬운 구독 연결과 이미지 생성 수정

GPT-6.1 Sol의 공식 이미지 도구를 호출하지 못하던 설정 충돌을 수정했습니다. 격리된 코드 모드 호스트를 켜고 셸·파일 조회·네트워크 도구·MCP·스킬·하위 에이전트 차단을 검증합니다. 실제 이미지 도구의 사용 한도 오류와 빈 결과도 구분합니다.

상단 **구독 연결**에서 **Codex 준비 → 공식 계정 연결 → 연결 확인** 순서로 시작하세요. Codex가 없으면 공식 0.160.0 배포본의 출처·150.15 MiB 용량·SHA-256·라이선스를 확인하고 동의한 뒤 앱 전용 공간에 준비합니다. 기존의 검증 가능한 Codex는 재사용하며 진행 확인·취소를 지원합니다. 로그인은 OpenAI 공식 페이지에서 진행하고 Node.js·Rust 설치와 PATH 변경은 필요 없습니다.

이 준비 기능의 동의 차단은 네이티브 Backend에서, 다운로드·압축·등록·취소 경계는 오프라인 fixture 12개에서 확인했습니다. 새 공식 패키지의 실제 다운로드·준비는 추가 다운로드 동의를 기다리는 별도 미검증 항목입니다.

[Windows 설치 파일](https://github.com/oocheol/masset/releases/download/v0.1.2/AssetStudio_0.1.2_x64-setup.exe) · [포터블 ZIP](https://github.com/oocheol/masset/releases/download/v0.1.2/AssetStudio-windows-x64-portable.zip) · [SHA-256](https://github.com/oocheol/masset/releases/download/v0.1.2/SHA256SUMS.txt) · [소스](https://github.com/oocheol/masset)

기존 0.1.1 설치 사용자는 앱의 **앱 업데이트**에서 0.1.2를 설치하세요. 0.1.0 포터블 사용자는 이번 설치 파일을 한 번 설치하면 이후부터 앱 안에서 업데이트할 수 있습니다. 업데이트 후 구독 연결을 확인하고 이미지를 새로 요청하세요. 원본·프로젝트·실패 기록은 보존하며 기존 실패 작업을 자동 재전송하지 않습니다.

수정된 Windows Backend에서 새 검증 요청 한 번으로 **1254×1254 PNG 수신·디코딩·저장·재열기·독립 내보내기**를 통과했습니다. 공식 Codex 0.160.0과 추론 모델 gpt-6.1-sol, 이미지 목표 gpt-image-2를 사용했습니다. 공개 이벤트가 실제 이미지 모델 ID를 제공하지 않아 confirmedModel=null을 유지합니다. 모든 계정의 권한이나 정확한 크기 제어를 보장하지 않습니다.
