# Asset Studio 0.1.8 · Windows 배포

2026-10-05에 Windows x64 공개 버전을 Mac의 0.1.8과 맞췄습니다. [설치 프로그램](https://github.com/oocheol/masset/releases/download/v0.1.8/AssetStudio_0.1.8_x64-setup.exe) 또는 [포터블 ZIP](https://github.com/oocheol/masset/releases/download/v0.1.8/AssetStudio-windows-x64-portable.zip)을 사용할 수 있습니다. 기존 Windows 0.1.1~0.1.3 설치 사용자는 앱의 업데이트 패널에서 0.1.8을 확인합니다.

## 변경 사항

- 게임 설명·프로젝트 루트 연결·개별 에셋 계획·제작·검수 화면을 기본 화면으로 제공합니다. Windows는 지원되는 이미지 모드로 시작합니다. 미지원 TripoSR 이미지→3D 계획은 외부 공급자를 호출하기 전에 차단하며, 기존 사용자의 계획은 동의 없이 바꾸지 않습니다.
- 편집 도구에서 기존 GLB를 다듬고 Blender 기본 소품을 만들 수 있습니다. 고해상도 원본을 보존하므로 삼각형 예산을 나중에 늘릴 때 이전에 줄인 메시 대신 보존된 형상을 사용합니다.
- Windows의 정규화된 경로 접두사, 한글·공백·긴 경로, 프로젝트 상태 교체를 수정했습니다. Blender 파일 I/O가 긴 경로를 직접 처리할 수 없을 때는 동일 파일인지 확인한 기존 짧은 경로를 사용합니다. 짧은 경로가 없는 경우 명확한 오류를 반환하며 원본을 옮기거나 파일시스템 설정을 바꾸지 않습니다.
- 설치형과 포터블에 명시된 작업자·문서·라이선스만 포함하고 빌드 당시의 파일별 해시와 대조합니다. Windows 타깃의 라이선스를 수집하고 누락·경로 이탈·심볼릭 링크·예상하지 못한 리소스를 검사합니다.
- 개발용 독립 내보내기 검사기가 게임용·고해상도·LOD 메시를 각각의 삼각형 수와 비교하도록 수정했습니다. LOD를 주 모델과 같은 크기로 요구하던 오류를 제거하고 잘못된 역할·해시·개수는 계속 거절합니다.

Windows 패키지 소스는 [`593f175`](https://github.com/oocheol/masset/commit/593f175157c952278d2b9110768e80bb09f2501a)입니다. 내보내기 검사기 수정은 후속 [`62b9ac5`](https://github.com/oocheol/masset/commit/62b9ac5d2cfd19ce062ce7e738f1668bfd022066)에 있으며 앱 바이너리에는 포함되지 않는 개발 도구입니다. 이미 공개된 `v0.1.8` 태그·Mac 바이너리·Mac 업데이트 키와 `latest-macos.json`은 유지했습니다.

## 실제 Windows 검증

Windows 개발 PC에서 MSVC·Windows SDK·Rust로 빌드하고 Blender 5.2.1 LTS와 WebView2로 실행했습니다. 기존 사용자의 설치본을 교체하지 않고 새 QA 폴더와 배포 ZIP·NSIS에서 추출한 실행 파일을 사용했습니다.

| 검사 | 확인한 결과 |
| --- | --- |
| 설치·포터블 파일 | 공개 설치 프로그램·ZIP의 바이트 수와 SHA-256 일치, ZIP 내부 375개 파일 일치, NSIS 리소스 368개 일치 |
| 설치형 실행 파일 | 포터블과의 차이는 공식 Tauri `UNK → NSS` 번들 표식 3바이트뿐임을 전체 바이트 비교로 확인 |
| 실제 앱 창 | 포터블·NSIS 추출 앱의 Tauri WebView·IPC·이미지 12개 디코딩·제작 화면·실제 프로젝트 폴더 읽기 |
| Windows 제작 모드 | 실제 플랫폼 상태로 이미지 기본 선택, 미지원 이미지→3D 차단. 화면 검사에서는 GPT 계획을 모의 처리하고 제출을 가로챔 |
| 기본 3D | 실제 Blender 상자 생성, 저장 GLB 해시·1m 치수·네이티브 asset 프로토콜 로드·WebGL 드로·픽셀 변화 |
| 로컬 백엔드 | 이미지 편집·아틀라스·노멀·Blender 모델 두 개·내보내기·재열기·원본 보존·명시적 캐시 재사용, 독립 파일 검사 33개 |
| GLB 다듬기 | 배포본에 포함된 작업자로 1,620개 삼각형 입력을 980개로 줄인 뒤 고해상도 소스를 사용해 1,620개로 복원, 버전 3개 유지 |
| 독립 재열기 | 저장된 각 버전의 해시를 확인한 복사본을 새 Blender 프로세스에서 열어 57개·53개 검사 통과. GLB·LOD·UV·노멀·텍스처·편집 가능한 `.blend`·원본 해시 확인 |
| 내보내기 | 별도 Three.js GLTFLoader·PNG 디코더로 26개 파일의 해시·실제 메시·재질·이미지·역할별 개수 확인 |
| 긴 경로 | 한글·공백을 포함한 짧은 경로와 367자 경로의 GLB·PNG·`.blend` 저장 및 별도 재열기, 동일 파일 별칭 확인 |
| 소스 회귀 | Rust 208개 통과·4개 명시적 제외, 프런트엔드·산출물 127개 통과·3개 제외, 마지막 검사기 수정 16개 통과, 브라우저 흐름 6개 통과 |
| 라이선스 | Windows 타깃 npm 20개·Cargo 310개, 원문 249개·MPL 소스 아카이브 5개, 누락 0개 |

Blender는 `--background --factory-startup --disable-autoexec --threads 2`로 실행했습니다. 모델 런타임을 내려받거나 새로운 외부 AI 요청을 보내지 않았습니다. 위 결과는 로컬 처리와 네이티브 동작의 증거이며 Windows 0.1.8에서 새로운 GPT 이미지를 수신했다는 증거는 아닙니다. 기존 Windows 구독 이미지 수신 기록은 0.1.2에, Mac의 실제 제작 기록은 [Mac 0.1.8](v0.1.8-macos.md)에 있습니다.

## 다운로드와 업데이트

| 파일 | 바이트 | SHA-256 |
| --- | ---: | --- |
| `AssetStudio_0.1.8_x64-setup.exe` | 22,499,602 | `5d0d974abf1991f645a6cbd960c3929b93d4043694e8e7ad5794254e7fd74214` |
| `AssetStudio-windows-x64-portable.zip` | 10,642,426 | `11072a007c0a244ab1027ab298479f6470b22307d71f0290dfb2d567588de4a0` |

공개 파일을 익명 다운로드해 위 해시를 대조했습니다. 기존 Windows 업데이트 키로 서명한 설치 파일의 인증된 버전 0.1.8, 변조 파일 거절, 버전 재사용 공격 거절을 확인했습니다. 고정된 공식 `tauri-plugin-updater 2.13.1`로 공개 `latest.json`과 설치 파일을 실제 다운로드하고 서명·바이트·해시를 확인했습니다. 이 검사는 같은 버전의 다운로드를 허용하는 QA 비교기를 사용하며 설치 프로그램을 실행하지 않습니다.

**검증하지 않은 범위:** 기존 Windows 설치본의 0.1.3→0.1.8 교체 설치·재시작, 깨끗한 PC에서의 최초 실행, Windows Authenticode 인증서, Windows TripoSR 이미지→3D. 앱 사용에는 WebView2가 필요하며 Blender 기반 기능에는 Blender 설치가 필요합니다. Windows 초기 포터블 사용자는 업데이트를 지원하는 최신 설치본을 한 번 직접 설치하세요.
