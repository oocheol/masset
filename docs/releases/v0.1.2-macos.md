## Mac 0.1.2 시험 배포

Apple Silicon과 Intel용 DMG를 각각 제공합니다. 로컬 이미지 편집·스프라이트·아틀라스 중심의 시험 배포입니다.

- [Apple Silicon DMG](https://github.com/oocheol/masset/releases/download/v0.1.2/AssetStudio_0.1.2_macos-arm64.dmg): 16,758,899 bytes, SHA-256 `077ab59fac87524cc9a6d71b1102d94a75a19dc45333d3e972ee483d0e18a028`
- [Intel DMG](https://github.com/oocheol/masset/releases/download/v0.1.2/AssetStudio_0.1.2_macos-x64.dmg): 17,942,253 bytes, SHA-256 `831838593432c1b0ed0744b1a7c2348f6f578fe0912b95533c6046c3f4231a40`

각각 실제 macOS 서버에서 DMG를 읽기 전용으로 마운트하고 새 폴더로 복사한 앱의 네이티브 WebView·예제 이미지·큰 글씨/가이드·IPC를 확인했습니다. 별도 네이티브 CLI Backend에서는 2D 처리·프로젝트 재열기·PNG/아틀라스·원본 해시를 검사했습니다. 복사한 앱의 2D 버튼 클릭으로 변환을 검증한 것과는 구분합니다.

로컬 ad-hoc 앱 번들 봉인과 파일 무결성 검사를 통과했습니다. Apple Developer ID 서명·공증은 적용하지 않았습니다. DMG를 열고 앱을 Applications로 복사하세요. 최초 실행은 macOS의 개인정보 보호 및 보안에서 해당 앱의 실행 허용이 필요할 수 있습니다. Gatekeeper 최초 다운로드·다른 실제 Mac 하드웨어·교체/제거는 미검증입니다.

Mac 구독 연결·Codex 자동 준비·앱 내부 업데이트는 지원하지 않습니다. Blender 3D의 Mac 실행은 미검증입니다. Windows의 공급자/업데이트 결과를 Mac에 적용하지 않습니다. macOS 12.0은 설정 최소값이며 실제 검사 OS는 위 메타데이터에 기록했습니다. Mac 전용 의존성 라이선스 원문·MPL 소스와 안내가 앱에 포함됩니다.

빌드 소스: `0674d189a9c85e6ef64810cc5b777fd149daf967`, [실제 검증 workflow](https://github.com/oocheol/masset/actions/runs/37113522134). 기존 Windows 설치 파일·ZIP·업데이트 manifest와 v0.1.2 태그는 보존합니다.

각 GitHub 공개 주소의 익명 다운로드에서 두 DMG의 용량·SHA-256이 검증 후보와 일치했습니다. Windows 업데이트 `latest.json`의 기존 바이트와 SHA-256도 유지됐습니다. [상세 메타데이터](v0.1.2-macos.json)를 참고하세요.
