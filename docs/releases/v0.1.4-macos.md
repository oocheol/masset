## 실제 Mac 검증

macOS 27.0.1 arm64에서 Rust 네이티브 테스트 141개, 아티팩트 테스트 30개가 통과했습니다. DMG를 마운트해 복사한 앱의 ad-hoc 봉인, 실제 WebView 이미지 12개와 IPC, 별도 production Backend의 2D 작업 6개·PNG 16개·프로젝트 재열기·독립 내보내기를 확인했습니다. 공개 DMG·설치 스크립트의 익명 다운로드 해시도 일치했습니다. README와 사이트에서 복사하는 동일한 설치 명령을 사용해 스크립트 검증 후 실제 공개 DMG로 새 앱을 설치했습니다.

공식 Tauri updater 2.13.1을 사용하는 **업데이트 기능이 추가된 0.1.3 테스트 사본 → 실제 0.1.4 배포 앱**의 설치를 확인했습니다. Mac 네이티브 업데이트 패널에서 승인 전 설치 비활성화·승인 후 활성화, GitHub 다운로드, 서명·서명된 버전·크기·해시 검증, 앱 번들 교체, 프로세스 재실행(PID 22409 → 22553)을 확인했습니다. 동일 프로젝트가 다시 열렸으며 프로젝트 설정·에셋 버전과 실제 파일 12개의 해시가 유지됐습니다. 독립 서명 검사는 변조 파일과 버전 재사용도 거부했습니다.

**이 테스트의 시작 앱은 현재 소스로 만든 업데이트용 사본입니다. 과거 공개 Mac 0.1.3은 업데이트 기능이 없으므로 0.1.4를 직접 한 번 설치해야 합니다.** 테스트 앱·프로젝트는 전용 출력 폴더에 격리했고 외부 공급자 작업은 요청하지 않았습니다.

브라우저 회귀 6개가 통과했습니다. 첫 Mac 브라우저 검사에서 Windows 전용 Control 다중 선택 입력이 실패해 테스트를 ControlOrMeta로 수정했습니다. 최초 DMG 빌드는 Finder 권한 미허용으로 실패해 기록을 보존했습니다. 사용자가 Finder 권한을 허용한 뒤 **일반 빌드에서 Finder 배치·DMG·서명된 업데이트 아카이브 생성이 성공**했습니다. 새 최종 파일로 DMG 설치·네이티브 실행·업데이트 교체·재실행·프로젝트 보존을 다시 확인했습니다.

## 검증 범위

Apple Developer ID와 공증은 없습니다. ad-hoc 앱 봉인·업데이트 서명은 Apple 공증과 다릅니다. 터미널 설치는 새 검증 사본에 브라우저 quarantine을 전달하지 않으며, 시스템 전체 Gatekeeper는 변경하지 않습니다. 브라우저 DMG 최초 실행에는 사용자가 해당 앱의 예외를 허용해야 합니다. 깨끗한 새 하드웨어·최소 macOS 12·Intel·Mac Codex 구독·Blender 3D·앱 제거는 검증하지 않았습니다.

업데이트 앱은 쓰기 가능한 폴더에 설치해야 합니다. 교체 전 이전 앱을 캐시에 백업하고, 교체 오류 시 복원을 시도합니다. 실제 성공 설치·재시작은 확인했으며 모든 OS 오류 조건의 복원을 검증했다고 주장하지 않습니다.
