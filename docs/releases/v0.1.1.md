# Asset Studio 0.1.1 — Windows 설치형

큰 글씨와 사용 가이드를 추가하고, GPT-6.1 Sol 추론 모델을 고정했습니다. 이미지 목표는 GPT Image 2이며 실제 구독 이미지 수신은 아직 확인되지 않았습니다.

[Windows 설치 파일](https://github.com/oocheol/masset/releases/download/v0.1.1/AssetStudio_0.1.1_x64-setup.exe) · [포터블 ZIP](https://github.com/oocheol/masset/releases/download/v0.1.1/AssetStudio-windows-x64-portable.zip) · [SHA-256](https://github.com/oocheol/masset/releases/download/v0.1.1/SHA256SUMS.txt) · [소스](https://github.com/oocheol/masset)

기존 0.1.0 포터블 사용자는 이번 설치 파일을 한 번 설치하세요. 이후에는 앱이 시작할 때와 10분마다 새 버전을 확인합니다. 파일 정보를 검토하고 동의한 뒤 업데이트를 누르면 서명·버전·크기·SHA-256 검사 후 제작 작업이 끝났을 때 설치·재시작합니다. 원본과 프로젝트는 보존합니다.

주요 버튼·입력란은 14px 이상, 사용 가이드는 16px입니다. 긴 기술 설명은 접었습니다. 상단 사용 가이드에서 가져오기, 편집, 3D 제작, 내보내기와 업데이트를 확인하세요.

설치 파일은 8,328,173 bytes, ZIP은 8,552,562 bytes입니다.

개발 Windows 호스트의 실제 포터블/설치형 창·12개 이미지·네이티브 IPC·큰 글씨와 가이드·Blender GLB 렌더, 백엔드 8개 작업·출력 33개, 새 Blender 프로세스 재열기 4회를 확인했습니다. 독립 서명/버전/변조 거부 검사와 같은 버전 NSIS 재설치·재시작·제거도 통과했습니다. 다른 버전의 실제 플러그인 설치, 깨끗한 다른 PC, macOS와 계정 모델 권한은 미검증입니다. [버전별 검증](../verification.md), [공급자 상태](../provider-feasibility.md), [ima2-gen 비교](../ima2-gen-comparison.md)를 참고하세요.

WebView2가 이미 설치되어 있어야 합니다. 설치 프로그램은 런타임을 자동 다운로드하지 않습니다. 3D용 Blender는 별도입니다. Node.js·Rust 개발 도구는 앱 사용에 필요하지 않습니다. Windows Authenticode 코드 서명은 없으며 업데이트 파일의 암호학적 서명과는 다릅니다.

코어 Apache-2.0, Blender 작업자 GPL-3.0-or-later, 포함된 제3자 구성요소의 라이선스·저작권 고지와 원본 소스 안내를 함께 제공합니다. 유료 API 전환이나 기존 실패 작업의 자동 재요청은 없습니다.
