# Asset Studio 0.1.11 · Mac 앱과 독립 Codex 스킬

2026-10-06 최신 master의 독립 스킬·런타임 준비 기능을 Apple Silicon Mac으로 빌드했습니다. Windows 0.1.11 설치 파일·독립 CLI·업데이트는 기존 공개 파일을 유지합니다.

- Mac DMG와 프로젝트 키로 서명한 앱 업데이트 파일을 추가했습니다.
- GUI 없이 사용하는 `AssetStudioCLI-0.1.11-macos-arm64.zip`을 추가했습니다. 실행 파일과 로컬 작업자·예제·라이선스를 포함하며 인증 파일과 모델 가중치는 포함하지 않습니다.
- `AssetStudio_0.1.11_codex-plugin-windows-macos.zip`에는 두 플랫폼 CLI의 크기·SHA-256·전체 파일 목록을 포함했습니다. 기존 Windows 전용 스킬 ZIP도 보존합니다.
- 스킬은 기존 공식 Codex 로그인을 재사용하고, 누락한 실행 도구와 3D 준비에 필요한 Blender·Python·TripoSR를 승인된 범위에서 사용자 전용 공간에 준비합니다. 유료 API로 대체하지 않습니다.

[Mac 설치 안내](../macos-quickstart.md) · [앱 없이 스킬 설치](../skill-first-setup.md) · [Codex 제작 흐름](../codex-integration.md)

## 빌드와 검증 범위

Mac이 잠겨 있어 사용자의 명시적 요청으로 실행 검증을 생략했습니다. 추가 단위 테스트, 독립 로더 설치 실행, 새 GPT 생성·로컬 3D 준비, DMG 설치·네이티브 화면·업데이트 교체 실행 검증을 수행하지 않았습니다. 프런트엔드와 Rust 네이티브 빌드, 실제 DMG·CLI ZIP·서명된 업데이트 생성 및 각 파일의 크기·SHA-256 기록은 배포 작업에 포함됩니다. 빌드 성공을 실제 실행 성공으로 표시하지 않습니다.

Apple Developer ID 서명·공증은 없습니다. 앱과 Mac CLI의 ad-hoc 서명, 프로젝트 키로 서명한 업데이트 파일은 Apple 공증과 구분합니다. Intel Mac은 제공하지 않습니다. [Windows 0.1.11 실행 검증](v0.1.11-windows.md)은 Windows만의 기록이며, 이전 Mac 검증은 [0.1.10 개발 기록](../codex-integration-validation.md)에 남깁니다.

새 파일과 업데이트 채널 정보는 [배포 메타데이터](v0.1.11-macos.json)와 릴리스의 `SHA256SUMS-macos.txt`를 확인하세요.
