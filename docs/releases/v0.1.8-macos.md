# Asset Studio 0.1.8 Mac 정식 배포 · 게임 프로젝트에서 에셋 제작

게임 설명과 기존 게임 프로젝트 루트를 연결해 필요한 시각 에셋을 분석하고, 개별 2D·3D 결과를 한 번에 제작·저장·검수하는 화면을 기본으로 제공합니다. 편집기는 별도 **편집 도구** 버튼으로 엽니다. 완료 카드의 **이 에셋 개선하기**는 기존 결과를 참고로 해당 에셋만 새로 만들 요청을 준비합니다.

GPT-5.5의 텍스트 제작 목록은 최대 120개입니다. 각 이미지와 3D 참고 이미지는 별도 구독 요청으로 생성합니다. 3D는 단일 물체 참고 이미지에서 로컬 TripoSR와 Blender를 거쳐 게임용 GLB·LOD·텍스처로 변환합니다. 고해상도 형상·Blender 원본·미리보기는 로컬 보관함에 유지합니다. 유료 API로 대체하지 않습니다.

프로젝트 분석은 파일 목록과 제한된 누락 참조를 읽습니다. 코드 내용과 자격 증명 파일을 GPT에 보내거나 게임 코드를 실행하지 않습니다. 검증한 결과는 새 `AssetStudioGenerated/<제작 ID>/` 폴더에 저장하고 기존 파일·장면 참조는 유지합니다. Unity는 `Assets/`, Unreal의 Content 폴더가 있는 경우는 `Content/` 아래에 저장합니다. 엔진 가져오기와 참조 자동 연결은 검증하지 않습니다. [사용 방법과 제작 범위](../game-production.md)를 확인하세요.

## Mac 실제 검증

2026-10-05, macOS 27.0.1 arm64·Apple M4 Pro·24GiB·CPython 3.9.6·Blender 5.2.1 LTS에서 확인했습니다. 기존 Godot 프로젝트의 누락 참조 두 개를 분석하고 실제 GPT 구성안을 받아 **Fuel Cell** 512×512 PNG와 **Basalt Asteroid** GLB를 독립 에셋으로 제작했습니다. 3개 작업을 한 번에 등록한 뒤 같은 시작 요청을 반복해도 중복 등록되지 않았습니다. 실제 GPT 이미지 응답은 확인 모델 ID를 제공하지 않아 `confirmedModel=null`로 기록했습니다.

첫 실행에서 준비 이미지 등록 누락을 발견해 새 버전으로 기록하도록 수정했습니다. 로컬 재시도에서 노멀 검사의 캐시 문제를 발견해 Blender가 실제 내보내기에 쓰는 코너 노멀을 검사하도록 수정했습니다. 원본 수신 이미지와 실패 기록을 보존했고, GPT 이미지를 다시 요청하지 않고 로컬 단계만 재시도해 완료했습니다. 결과 해시·게임 파일 보존·검수 상태의 재열기를 확인했습니다.

소행성의 고해상도 형상은 109,899개 삼각형이고 게임용은 9,769개, LOD는 4,771개입니다. 새 Blender 프로세스에서 GLB·LOD·`.blend`·텍스처·UV·실제 노멀·턴테이블을 다시 열어 **56개 검사**를 통과했습니다. Blender는 `--factory-startup --disable-autoexec`로 실행합니다. 원래 게임 파일 세 개의 해시와 개별 결과 전달 해시를 유지했습니다. 파일별 해시는 [제작 검증 메타데이터](v0.1.8-macos.json)에 있습니다.

Mac Rust 검사 **209개**와 프런트엔드·산출물 검사 **95개**를 통과했습니다. 실제 제작 증거는 네이티브 백엔드 실행에서 얻었습니다. 설치본의 실제 Tauri WebView·IPC·폴더 분석·기본 제작 화면·이미지 12개 디코딩도 확인했습니다. 화면 검사의 GPT 계획과 로컬 준비 상태는 모의 처리하고 제출을 가로채므로 실제 생성 증거와 구분합니다. 화면이 잠겨 있어 3D 뷰포트의 GPU 픽셀 검사는 완료로 표시하지 않습니다.

## 설치와 배포 검증

최종 DMG(34,515,783 bytes)의 SHA-256은 `f0b15569c67aaf41f4a31b262a31fccc1a6b3f7f26257ac3565864ad8d2ad176`입니다. 실제 마운트, 앱 복사, 번들 봉인, arm64 실행, Tauri WebView·IPC·프로젝트 분석, 이미지 12개 디코딩, 네이티브 2D 내보내기와 재열기, 원본 보존, 마운트 해제를 통과했습니다. 설치 스크립트로 별도 폴더에 설치하는 과정도 통과했습니다.

업데이트 아카이브는 **31,314,425 bytes**, SHA-256 `95c9b7f3c81b0b27082a30f531c17c3639ddfd75ddd83ead88d12265d0ed3e00`입니다. 별도 업데이트 키의 서명과 인증된 0.1.8 버전을 확인했습니다. 공개 파일 7개의 해시를 검증하고, 공개 0.1.6 앱에서 0.1.8의 실제 다운로드·서명 검증·설치·재시작·프로젝트 재열기를 통과했습니다. 원본 및 결과 파일 12개의 해시를 유지했습니다. 배포 상태는 [배포 검증 기록](v0.1.8-distribution.json)에 기록합니다.

Mac 0.1.8 정식 배포용 파일입니다. Apple Developer ID 서명·공증은 포함하지 않으므로 [Mac 설치 안내](../macos-quickstart.md)를 따르세요. 이 Mac 배포를 검증한 시점에는 Windows가 **0.1.3**이었으며 해당 사실은 기존 JSON 기록에 보존합니다. 이후 별도 Windows 네이티브 빌드·검증을 거쳐 **0.1.8 설치형·포터블·업데이트 채널**을 추가했습니다. [Windows 후속 배포 기록](v0.1.8-windows.md)을 확인하세요. Mac 파일·서명·업데이트 채널은 변경하지 않았습니다.

## 결과 범위

목록은 최대 120개 시각 에셋이며 실제 이번 일괄 생성은 두 개로 검증했습니다. 리깅·애니메이션·음원·코드·CAD·다중 물체 장면과 완성된 게임 전체를 보장하지 않습니다. 구형 TripoSR은 현재 Tripo Studio의 모델과 다르고 뒷면·미세 형상·재질·스케일에는 추정 한계가 있습니다. 3D 준비에는 Apple Silicon·CPython 3.9·Blender·최소 16GB 메모리가 필요합니다. Apple Developer ID·공증, Intel·최소 macOS 12·깨끗한 기기의 최초 Gatekeeper 수락은 검증하지 않았습니다.
