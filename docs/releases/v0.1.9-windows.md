# Asset Studio 0.1.9 · Windows 이미지→3D

Windows x64의 제작 화면에서 **이미지·3D·혼합**을 선택할 수 있습니다. Mac 전용 안내와 Windows 차단을 해제하고, 해시가 고정된 앱 전용 Python·PyTorch CPU·TripoSR 준비 기능을 추가했습니다. Mac 다운로드와 업데이트 채널은 기존 검증된 0.1.8을 유지합니다.

[Windows 설치 프로그램](https://github.com/oocheol/masset/releases/download/v0.1.9/AssetStudio_0.1.9_x64-setup.exe) · [포터블 ZIP](https://github.com/oocheol/masset/releases/download/v0.1.9/AssetStudio-windows-x64-portable.zip) · [릴리스](https://github.com/oocheol/masset/releases/tag/v0.1.9)

## 사용하기

1. 기존 설치 사용자는 앱 업데이트 패널에서 0.1.9를 설치합니다. 초기 포터블은 최신 설치본 또는 전체 ZIP을 새 폴더에 준비합니다.
2. 제작 화면에서 **로컬 3D 준비**를 열고 출처·용량·라이선스를 확인한 뒤 다운로드에 동의합니다. Python과 모델은 앱 전용 공간에 준비하며 시스템 Python은 변경하지 않습니다.
3. Blender와 최소 16GB RAM, Microsoft Visual C++ 2015–2022 x64 런타임이 필요합니다. 해당 런타임이 없으면 공식 설치 안내를 표시하고 모델 다운로드를 시작하지 않습니다.
4. 이미지·3D·혼합을 선택해 제작 목록을 검토합니다. 편집 도구의 **3D 만들기**에서는 투명 배경의 단일 물체 이미지를 직접 선택할 수도 있습니다.

첫 준비 다운로드는 **2,034,000,316바이트(약 1.89GiB)**입니다. CPython 3.12.10, PyTorch 2.2.2 CPU, 고정 TripoSR 코드·모델과 의존성의 원본 크기·SHA-256·라이선스는 [Windows 잠금 명세](../../workers/image3d/runtime-lock-windows.json)에 있습니다. Python.org·공식 PyTorch CPU 배포처·PyPI·GitHub·Hugging Face에서 확인한 파일만 받습니다. 준비 이후 CPU 추론은 오프라인으로 실행하며 CUDA나 유료 API는 필요하지 않습니다.

## 실제 확인한 범위

2026-10-06 한국 시간, Windows 11 x64 / i5-12400F / RAM 64GiB에서 검증했습니다. 입력은 저장소의 CC0 `blue-sphere.png`입니다. 새 GPT 이미지를 요청한 실증과 구분합니다.

| 검사 | 실제 결과 |
| --- | --- |
| 관리형 런타임 | CPython 3.12.10·37개 패키지·고정 모델 해시, CPU 연산과 marching cubes 실행 확인 |
| 실제 standard 추론 | CPU 2스레드, 57.188초, peak RSS 3,663,228,928바이트, 원본 메시 23,244삼각형 |
| Blender 처리 | 게임용 9,793 / LOD 4,792삼각형, UV·텍스처·고해상도 형상·`.blend`·썸네일·턴테이블 저장 |
| 네이티브 백엔드 | 원본 이미지 유지, 별도 Model 에셋, 정확한 생성 보고서·프로젝트 재열기·독립 내보내기 통과 |
| 독립 재열기 | 프로젝트 산출물 16개·내보내기 파일 17개 해시·크기 일치, 별도 Blender에서 GLB·`.blend` 재열기 통과 |
| Blender 텍스처 | packed PNG 3개와 별도 basecolor·normal·orm 파일의 SHA-256 일치, 실제 512² 픽셀 디코드 확인 |
| 제작 화면의 전달 경로 | high CPU 추론 73.672초, 실제 모델 처리·게임 폴더에 GLB·LOD·텍스처 5개 전달, 입력과 기존 게임 파일 해시 보존 |
| 독립 내보내기 검사기 | 실제 내보낸 17개 파일 통과. raw/high는 생성 보고서와 역할 선언으로 구분하고 정점색·형상을 검사하며 게임용·LOD의 UV·재질 검사는 유지 |
| 회귀 검사 | 최신 master 통합 후 Rust 215개 통과·5개 명시적 제외, 프런트엔드·산출물 151개 통과·3개 제외, 최종 검사기 25개 통과, 브라우저 흐름 6개 통과 |
| 중단 복구 | 준비 프로세스 강제 종료 시 OS 잠금 해제, 기존 파일 보존·재시도와 동시 설치 차단 확인 |

Blender는 `--background --factory-startup --disable-autoexec --threads 2`로 실행했습니다. 첫 draft 실행에서는 프로젝트 JSON 파서의 소수점 정밀도 차이로 생성 메타데이터 일치 검사가 실패했습니다. `serde_json/float_roundtrip` 적용 후 정확한 수치 보존 회귀 검사와 새 standard 실행 전체 검증을 통과했습니다. 실패한 원본 증거는 보존했습니다.

검증 메타데이터와 최종 설치 패키지 정보는 [v0.1.9-windows.json](v0.1.9-windows.json)에 기록합니다. 작업자 직접 실행 기록은 [Windows worker proof](../../workers/image3d/tests/native-proof-windows.json)에 별도로 있습니다.

**확인 범위의 한계:** 깨끗한 PC에서의 최초 설치, 기존 사용자의 설치본 교체·재시작, Windows Authenticode 코드 서명, 이번 버전의 새 GPT 요청·모든 계정의 모델 권한은 검증하지 않았습니다. TripoSR은 구형 단일 이미지 추정 모델이며 입력에 따라 뒷면과 형상이 부정확할 수 있습니다. 리깅·쿼드 리토폴로지·물리 치수 정확도는 제공하지 않습니다. 업데이트 파일 서명은 Windows 코드 서명과 별개입니다.
