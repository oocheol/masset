# Asset Studio 0.1.0 — Windows portable

첫 공개 Windows x64 포터블 버전입니다. 원본을 보존하는 이미지 변환, 스프라이트·아틀라스, 절차적 Blender 소품, 로컬 프로젝트와 작업 큐를 제공합니다.

[Windows ZIP 다운로드](https://github.com/oocheol/masset/releases/download/v0.1.0/AssetStudio-windows-x64-portable.zip) · [SHA-256](https://github.com/oocheol/masset/releases/download/v0.1.0/SHA256SUMS.txt) · [소스](https://github.com/oocheol/masset)

ZIP은 6,922,222바이트이며 SHA-256은 아래와 같습니다.

```text
d21672dfcc0f3c65ca574d91bccdf7595db705ddc3d287644a6977575dc55b02  AssetStudio-windows-x64-portable.zip
```

ZIP 전체를 새 폴더에 풀고 `asset-desktop.exe`를 실행하세요. 함께 있는 `examples`와 `workers` 폴더를 유지하세요. 앱 이용에 Node.js·Rust·Visual Studio는 필요하지 않습니다. Windows WebView2가 필요하고, 3D 작업에는 Blender를 별도로 설치해야 합니다. [첫 사용 안내](../windows-quickstart.md)를 참고하세요.

개발 Windows 호스트에서 포터블 앱의 실제 창, 2D 파일, 네이티브 명령, Blender 모델 생성 및 GLB 렌더를 확인했습니다. 상자·테이블의 GLB와 `.blend`는 새 Blender 프로세스에서 총 4회 다시 열어 검사했습니다. [검증 기록](../verification.md)과 [공개 배포 메타데이터](v0.1.0.json)에 범위를 기록했습니다.

실행 파일은 미서명입니다. 다른 Windows PC의 실행과 설치·업그레이드·제거는 아직 검증하지 않았습니다. macOS 다운로드는 준비 중입니다. GPT Image 2 구독 연결은 구현했지만 실제 이미지 파일 수신은 확인하지 못했습니다. 유료 API로 자동 전환하지 않습니다. 밝기 기반 노멀맵은 실험 기능입니다.

코어는 Apache-2.0, Blender 작업자 소스는 GPL-3.0-or-later입니다. Blender 실행 파일은 포함하지 않습니다. 라이선스와 제3자 고지는 ZIP 안에 함께 제공합니다.
