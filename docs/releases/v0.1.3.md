# Asset Studio 0.1.3

소개 사이트와 프로그램을 같은 에셋 작업대 디자인으로 변경했습니다. 짙은 남색 패널, 청록색 선택 표시, 각진 검사 프레임을 적용하고 작은 화면의 한글 줄바꿈을 다듬었습니다. 버튼 14px 이상·가이드 16px와 기존 기능을 유지합니다. [디자인 규칙](../design-system.md)을 참고하세요.

- [Windows 설치 파일](https://github.com/oocheol/masset/releases/download/v0.1.3/AssetStudio_0.1.3_x64-setup.exe): 20,417,597 bytes
- [Windows 포터블 ZIP](https://github.com/oocheol/masset/releases/download/v0.1.3/AssetStudio-windows-x64-portable.zip): 9,563,536 bytes
- [Apple Silicon DMG](https://github.com/oocheol/masset/releases/download/v0.1.3/AssetStudio_0.1.3_macos-arm64.dmg): 16,759,756 bytes

Intel Mac 빌드와 현재 다운로드 선택지는 사용자 요청으로 제외했습니다. 기존 0.1.2 파일과 태그는 보존합니다.

Windows 최종 ZIP의 EXE에서 네이티브 WebView·예제 이미지 12개·IPC·글씨 크기·가이드·Esc와 포커스를 검사했습니다. 별도 CLI 2D 처리와 실제 Blender GLB 로딩·WebGL 픽셀 검사, 브라우저 회귀 6개가 통과했습니다. 공개 파일의 익명 다운로드 SHA-256과 ZIP 321개 파일이 일치하며, 실제 공식 Tauri 다운로드에서 서명·버전을 확인했습니다. 이 검사는 기존 설치 앱의 교체나 깨끗한 PC 인증을 대신하지 않습니다.

Apple Silicon은 [성공한 네이티브 작업](https://github.com/oocheol/masset/actions/runs/37133673261/job/111233686896)의 DMG를 사용했습니다. Rust 138개, 실제 DMG 마운트·새 폴더의 복사 앱·ad-hoc 파일 봉인·WebView/가이드/IPC와 별도 CLI 2D PNG/아틀라스 검증이 통과했습니다. 같은 workflow의 Intel 작업을 취소해 전체 run의 결론은 cancelled이며, Apple Silicon job은 success입니다. 구독 연결·관리형 Codex·앱 내부 업데이트는 Mac 미지원이고 Blender 3D, Apple Developer ID·공증·Gatekeeper 최초 다운로드·최소 macOS 12·실제 다른 하드웨어의 설치/교체는 미검증입니다. 실제 실행 OS는 macOS 15.7.9입니다.

이번 디자인 변경에서 외부 이미지 생성 요청은 하지 않았습니다. 0.1.2의 Windows 이미지 한 장 실증은 역사 기록으로 유지합니다. [Windows 메타데이터](v0.1.3.json)와 [Mac 메타데이터](v0.1.3-macos.json)에 실제 해시와 범위를 기록했습니다.
