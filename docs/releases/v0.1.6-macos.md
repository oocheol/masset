# Asset Studio 0.1.6 · Mac 게임 에셋 묶음

게임 설명과 참고 이미지·GLB를 넣고, 개별 에셋 목록을 검토한 뒤 한 번에 제작합니다. 이미지 수 5는 서로 다른 에셋 5개이며 항목마다 별도 요청·파일·작업을 만듭니다. 동일 에셋의 여러 변형은 별도로 선택합니다. 기존 2D 개선은 원본을 보존한 새 버전입니다. 3D는 아홉 가지 고정 Blender 레시피의 새 GLB·.blend·렌더를 제공합니다. 임의 메시 복원은 지원하지 않습니다.

2026-10-04, macOS 27.0.1 arm64에서 검증했습니다. 배포 패키지 소스는 `795a1ab26c07c837f89554ecee569c2f938ff3c2`입니다. 실제 구독 생성 증거는 `a52f52a0697fd24a7c1136f9c222c9880a0b5c72`의 네이티브 백엔드에서 얻었으며, 이후 변경은 UI 검사 도우미와 문서·배포 정보입니다. Windows 공개 버전은 0.1.3입니다.

## 개별 이미지·모델의 실제 결과

공식 구독 경로로 GPT-5.5의 텍스트 구성안을 받아 개별 무기 PNG 5장과 모델 2개를 제작했습니다. PNG 5장을 각각 열어 무기 하나씩 들어 있음을 확인했습니다. 한 번의 원자적 큐 등록, 반복 제출의 중복 방지, 저장·재열기·28파일 독립 내보내기를 통과했습니다. 이미지·모델 참고 원본은 그대로 보존했습니다. 두 GLB와 두 .blend를 별도 Blender 프로세스에서 다시 열어 파일 해시·치수·UV·재질을 확인했습니다. Blender는 스크립트 자동 실행을 끕니다. 실제 응답 이미지 모델 ID는 null입니다. [파일별 실제 결과](v0.1.6-game-bundle.json)를 확인하세요.

최종 DMG의 복사본에서 실제 Tauri WebView·Mac IPC·원본 이미지 12개와 새 묶음 화면을 확인했습니다. 화면 검사는 공급자 준비와 구성안 응답을 명시적으로 모의 처리하고 제출을 가로채어, 개별 행 5개·이름 수정·항목 제외·검토 승인·4항목 제출을 검사했습니다. 공급자 요청과 실제 작업은 만들지 않습니다. 실제 생성 증거와 화면 모의 검사를 구분합니다. 별도 네이티브 백엔드의 로컬 작업 6개·PNG 16개·내보내기도 통과했습니다.

## 배포·설치·업데이트

- DMG: `AssetStudio_0.1.6_macos-arm64.dmg`, 29,188,590바이트, SHA-256 `79055cd2fbc81a658d480ebcb4e6418d3f15c793c6803fc86d19914f6fea0eb7`.
- 서명된 업데이트: `AssetStudio_0.1.6_macos-arm64.app.tar.gz`, 30,136,803바이트, SHA-256 `7c396f38fbaa877c35befcfa89809a3f00f8964dee49e0a58ca555d93640f90e`.
- 설치 스크립트: SHA-256 `0127c9b90f1995a35c36b593ed721a3d4ec798c3216452e8703cc6a75c3747be`. 실행 전 스크립트 해시를 확인한 뒤 실제 공개 DMG를 다운로드·검증해 새 사본을 설치했습니다.

GitHub 파일 8개의 익명 다운로드가 빌드 파일과 일치했습니다. Finder 레이아웃을 사용하는 일반 DMG 빌드, 실제 마운트·복사·봉인·리소스·라이선스 검사를 통과했습니다. 현재 `/Applications/Asset Studio.app`의 353개 파일·링크·실행 권한 항목은 공개 DMG와 일치합니다. 기존 프로젝트 파일 36개의 해시가 유지됐으며, 이전 앱은 복구 가능한 백업으로 보존했습니다.

과거 실제 공개 0.1.5 앱을 별도 QA 폴더로 복사해 네이티브 승인 UI와 공식 Tauri 공개 후보 다운로드·서명·버전 검사, 0.1.6 설치·새 PID 재실행을 통과했습니다. 프로젝트·버전·원본 해시와 이미지 12개가 그대로 유지됐습니다. 공개 최신 채널에서도 공식 Tauri의 실제 메타데이터 확인·다운로드·서명·버전 검증을 통과했습니다. 0.1.3 이하는 Mac 업데이트 기능이 없어 최신 앱을 한 번 직접 설치해야 합니다.

173개 Mac Rust 테스트, 40개 파일·UI 단위 검사, 6개 브라우저 회귀 검사가 통과했습니다. Windows 네이티브 테스트에서 고정 모델 목록의 줄바꿈 변경을 발견해 원본 바이트 보존을 강제했습니다. 최종 Mac 대상 라이선스는 npm 20개·Cargo 316개·라이선스 텍스트 257개·MPL 소스 5개이며 누락은 없습니다.

## 검증 범위

Asset Studio는 ad-hoc 코드 서명이며 Apple Developer ID·공증은 없습니다. 업데이트의 별도 서명과 공식 Codex의 OpenAI Developer ID 확인은 다른 검사입니다. 최소 macOS 12, Intel, 깨끗한 하드웨어와 최초 Gatekeeper 수락은 검증하지 않았습니다. 잠긴 화면에서 3D 뷰포트 픽셀 검사 완료를 확인하지 못해 해당 항목을 검증 통과로 기록하지 않았습니다. 실제 3D 생성·렌더 파일·GLB/.blend 재열기 검사는 별도로 통과했습니다. 초기 실패와 중단 기록은 보존했습니다.
