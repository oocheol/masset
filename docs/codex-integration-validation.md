# Codex 연동 검증 · 0.1.10

2026-10-06 Apple Silicon Mac에서 확인했습니다. 아래 결과는 Windows 0.1.9 변경을 합치기 전의 로컬 설치·소스 검증입니다. 최종 Mac 0.1.10 배포본의 추가 설치·네이티브 화면·업데이트 실행 테스트는 사용자의 요청으로 생략했습니다. 이 개발 기록을 최종 DMG 검증으로 표시하지 않습니다.

| 확인 대상 | 실제 결과 |
| --- | --- |
| 설치된 네이티브 CLI | 개발 체크아웃 경로 없이 앱 리소스 탐색과 `doctor` 실행 |
| GPT 구독 제작 | 개별 PNG 수신, 게임 프로젝트의 새 폴더 저장, 전달 해시 검증 |
| 요청 이어받기 | 같은 UUID로 완료된 작업을 다시 읽음. GPT 실행 파일을 사용할 수 없는 조건에서도 추가 생성 없이 성공 |
| 파일 변조 | 테스트 PNG의 해시를 변경하면 전달 검증 거부. 원본 복원 |
| 로컬 3D | 실제 GLB 가져오기·다듬기·새 버전 저장·내보내기. 독립 파일 검사 통과 |
| 기존 제작 복구 | 참고 이미지 재생성 없이 실패한 3D 항목 두 개 복구. 각각 별도 Blender 프로세스의 GLB·`.blend` 재열기 검사 70개 통과 |
| 앱 무결성 | 실제 모델 처리 뒤 앱의 ad-hoc 코드 서명 봉인 검증 통과. Blender가 앱 내부 Python 캐시를 쓰지 않도록 수정 |
| 스킬 설치 | 관리형 갱신·백업, 사용자가 편집한 스킬 보존, 실제 사용자 설치 확인 |
| Codex 탐색 | `skills/list`에서 사용자 `asset-studio` 스킬이 활성화됨. 이 검사에서 생성 요청·새 작업 없음 |
| 코드 검사 | Rust 데스크톱 68개, 스케줄러 35개, Windows 리소스 파일을 제외한 UI·아티팩트 테스트 108개 통과. 타입 검사와 데스크톱·사이트 빌드 통과 |

새 스킬 설치 버튼의 네이티브 화면 검증은 Mac 잠금으로 완료하지 못했습니다. 버튼의 UI 테스트와 같은 설치 함수를 사용하는 실제 CLI 설치는 통과했습니다. 전체 JS 테스트에서 Windows 리소스 패키징 검사 5개는 Mac 임시 폴더 경로 별칭 문제로 실패했으며, 해당 경로는 이번 변경 대상에 포함하지 않았습니다. 새로운 Windows 실행·패키징, 모바일 성능, Codex가 게임 전체를 만들어 플레이 완료하는 검증은 수행하지 않았습니다.

스킬의 암묵 선택은 작업 설명과 모델 판단에 따릅니다. 탐색에 성공했다고 모든 게임 요청에서 자동 선택된다고 보장하지 않습니다. 확실히 지정하려면 `$asset-studio`를 사용하세요. 사용 방법은 [Codex 연동 안내](codex-integration.md)를 참고하세요.
